Quera College is a Massive Open Online Course (MOOC) platform for interactive problem-based programming courses that I developed during my time as a Software Developer at Quera (2018-2019).

## Key Features

- **Interactive Problem-Based Learning**: Students learn programming through solving real-world problems
- **Scalable Platform**: Served more than 10,000 users during development
- **Backend Development**: Built using Python and Django framework
- **Full-Stack Responsibility**: Responsible for the entire backend architecture and implementation

## Impact

The platform has successfully educated thousands of students in programming fundamentals. I was also responsible for designing the curriculum for "Fundamentals of Programming and Algorithmic Thinking," which has been attended by more than 6,300 students.

## Technical Details

- **Technology Stack**: Python, Django
- **Role**: Software Developer, Curriculum Designer
- **Duration**: 2018-2019
